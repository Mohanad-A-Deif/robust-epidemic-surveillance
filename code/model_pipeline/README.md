# Model and experiment pipeline

This directory contains the revised proposed estimator, internal ablations, simplified external baseline implementations, evaluation metrics, statistical analyses, and publication-figure generators.

From the repository root:

```bash
python scripts/run_quick_smoke.py
```

For full studies, use `final_study.py`, `synthetic_study.py`, and the configurations under `configs/`. The included `results/` directory contains the frozen outputs used for the revised manuscript.
