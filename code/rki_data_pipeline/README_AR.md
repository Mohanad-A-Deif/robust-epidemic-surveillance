# حزمة تجهيز بيانات RKI الحقيقية وشبه الواقعية

هذه الحزمة تجهز تجربة البيانات الحقيقية للبحث، ولا تحتوي على نتائج مصطنعة جاهزة.

## ما الذي تستخدمه الحزمة؟

- بيانات يومية حقيقية من معهد روبرت كوخ الألماني RKI.
- ست ولايات ألمانية مترابطة جغرافيًا.
- الفترة: من 20 فبراير 2020 إلى 18 فبراير 2021.
- الحالة الوبائية: العدد اليومي المتوقع للحالات بحسب تاريخ بدء الأعراض، بعد جمع الفئات العمرية.
- التأخير والفقد والقيم الشاذة تُضاف بصورة محكومة وقابلة لإعادة الإنتاج.

## التشغيل السريع على Windows

افتح مجلد الحزمة وشغّل:

```bat
run_windows.bat
```

أو من PowerShell / CMD:

```bat
python -m pip install -r requirements.txt
python run_pipeline.py
```

سيقوم البرنامج بتنزيل ملف RKI الرسمي، والتحقق من بصمة MD5، ثم إنتاج ملفات البيانات والسيناريوهات.

## اختبار الحزمة دون إنترنت

```bat
python tests\test_pipeline.py
```

الاختبار يستخدم عينة صغيرة من صفوف RKI الأصلية للتحقق من صحة الكود فقط، ولا يجوز استخدامها كنتائج للبحث.

## تنبيه علمي

شبكة الحدود الجغرافية ليست الجراف الحقيقي للعدوى، ولذلك لا يجوز حساب Graph Support F1 عليها باعتبارها `W*` حقيقية. في البيانات الواقعية سنقيّم الجراف من خلال الاستقرار، القدرة التنبؤية، الندرة، والاتساق مع شبكة الحدود. أما استرجاع `W*` عدديًا فيبقى ضمن التجارب الصناعية التي نعرف فيها الحقيقة الأرضية.
