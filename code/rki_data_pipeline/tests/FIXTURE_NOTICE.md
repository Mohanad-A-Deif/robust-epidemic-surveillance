# Offline fixture notice

`rki_fixture.csv` is a tiny extract of genuine rows from the official RKI source,
restricted to Baden-Württemberg and Bayern for 20–22 February 2020. It exists
only to test parsing, age-group aggregation, transformations, chronological
splitting, and message-level corruption logic without internet access.

It is not an analysis dataset and must not be used to report manuscript results.
Source attribution: Robert Koch Institute (RKI), StopptCOVID Study Data,
DOI 10.5281/zenodo.10888033, CC BY 4.0.
