## `figures/`

Twenty grayscale, white-background PNG figures at 600 DPI, including benchmark, sensitivity, model mismatch, graph recovery, convergence, significance, runtime–accuracy, and scalability figures.

## `raw/`

Seed-level metrics, validation tuning results, paired statistical tests, uncertainty summaries, graph stability outputs, prediction arrays, and protocol manifests.

Results are retained even when a baseline outperforms the proposed method. See `docs/RESULTS_SUMMARY.md` for interpretation.
